Privacy Policy

Ductor Assistant · last updated 1 October 2026

Ductor Assistant is a private, single-user application. The only person who can authorise it, and the only person whose data it ever touches, is its operator and owner.

What data the app accesses

With the operator's explicit Google consent, the app requests access to:

  • Google Drive — to read and write the operator's own files.
  • Google Calendar — to read and create the operator's own events.
  • Google Sheets — to read and update the operator's own spreadsheets.
  • Google Tasks — to read and update the operator's own task lists.
  • YouTube (upload only) — to upload videos to the operator's own channel. This scope grants no ability to read or modify anyone else's content.

Where the data goes

Nowhere else. The app runs on a server controlled by the operator. Data fetched from Google is used to answer the operator's own requests and is not sold, shared, published, or transmitted to any third party. There is no analytics, no advertising, and no tracking.

What is stored

An OAuth refresh token is stored on the operator's server in a file readable only by the account that runs the app (chmod 600). It exists so the app does not have to ask for sign-in on every request. No Google passwords are ever seen or stored by the app.

Retention

Content retrieved from Google is held only as long as it is needed to carry out the request that asked for it. Nothing is archived for later analysis.

How to revoke access

Access can be withdrawn at any time at myaccount.google.com/permissions. Revoking immediately invalidates the stored token, and the app loses all access.

Limited Use

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
